# Export the train-only ALS V1 bundle

Run this as a **new code cell** in the executed `07_hybrid_recommender` notebook after the cell that fits the train-only ALS model and creates `Q_als`. Run the notebook's data-loading/setup cells first so `S`, `NAME`, `train`, `REL`, and `n_items` exist. Do not export the older `models/als_implicit.npz` file: this bundle must come from the current train-only fit.

The output is one compact runtime asset, `models/als_v1_bundle.npz`. It contains item factors and the matching display catalogue needed by the app; it does not contain validation/test interactions or evaluation reports.

```python
from pathlib import Path
import numpy as np
import pandas as pd

# The variables below must come from the current train-only fit in this notebook.
assert "Q_als" in globals(), "Run the train-only ALS refit cell first."
assert "S" in globals() and "train" in globals()
assert "NAME" in globals() and "REL" in globals() and "n_items" in globals()

# Movie metadata is joined to the split's item map, preserving the model's row order.
movies_path = Path("../data/interim") / NAME / "movies.parquet"
movies = pd.read_parquet(movies_path)
item_meta = (
    S["item_map"][ ["movieId", "i"] ]
    .merge(movies[["movieId", "title", "genres"]], on="movieId", how="left")
    .sort_values("i")
    .reset_index(drop=True)
)

assert len(item_meta) == n_items == Q_als.shape[0]
assert np.array_equal(item_meta["i"].to_numpy(dtype=np.int64), np.arange(n_items))
assert np.isfinite(Q_als).all()

# Only ratings >= REL in the training split determine the popularity fallback.
positive_train = train.loc[train["rating"] >= REL, "i"].to_numpy(dtype=np.int64)
positive_counts = np.bincount(positive_train, minlength=n_items).astype(np.int32)

# Store labels as fixed-width Unicode so the app can load the bundle with allow_pickle=False.
bundle_path = Path("../deployment/als_v1/models/als_v1_bundle.npz")
bundle_path.parent.mkdir(parents=True, exist_ok=True)
np.savez_compressed(
    bundle_path,
    Q=Q_als.astype(np.float32),
    movie_ids=item_meta["movieId"].to_numpy(dtype=np.int64),
    titles=item_meta["title"].fillna("Unknown title").astype(str).to_numpy(dtype=str),
    genres=item_meta["genres"].fillna("").astype(str).to_numpy(dtype=str),
    positive_counts=positive_counts,
)

print(f"Saved: {bundle_path.resolve()}")
print(f"Item factors: {Q_als.shape}; catalogue rows: {len(item_meta):,}")
print(f"Bundle size: {bundle_path.stat().st_size / (1024**2):.2f} MiB")
```

Before publishing, confirm that `Q_als` was generated by the train-only fit (`ratings >= 4`, 64 factors, alpha 5, regularization 80, 10 iterations). Do not use a model that was refit on train+validation for the validation-baseline deployment.
